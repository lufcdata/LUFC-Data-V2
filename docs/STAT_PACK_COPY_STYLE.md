# Stat Pack copy style

Use third-person British football language throughout.

## Prefer
- Leeds have...
- Leeds are looking to...
- [Player] has...
- for the first time since...
- their longest run since...
- their biggest winning margin since...
- completed a league double...
- kept a clean sheet / clean sheets

## Avoid
- we / our / us
- shutout
- recorded archive (unless coverage genuinely requires qualification)
- this fixture at that venue
- completed that run
- database population/query language in published copy
- ordinal bugs such as 2th

Numbers one to nine may be written as words in prose where natural; preserve figures when the statistic is easier to scan numerically or part of W-D-L notation.

Lead with the story, not the calculation. Evidence/provenance belongs in evidence metadata, not the publication sentence.
