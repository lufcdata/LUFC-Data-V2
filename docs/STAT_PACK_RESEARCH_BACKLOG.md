# Stat Pack Gold research backlog

Priority is historical significance, not card volume.

## Next families

1. Team streak historical ceiling: current run → all-time maximum → previous equal/better run → last occurrence.
2. Player-conditioned team streaks: W/D/L when starting; consecutive unbeaten/wins; scoring/assisting conditions.
3. Opponent scoring history: consecutive scoring/non-scoring, clean sheets, winless/unbeaten, goal-margin extremes.
4. Geographic concentration: season/career outcomes disproportionately concentrated in an authoritative city/region.
5. Geographic historical comparison: city record versus other cities using meaningful minimum samples.
6. Player geographic leaderboards: P/W/D/L, goals, assists, clean sheets where authoritative.
7. Season league-double totals and club-history rankings.
8. Contemporary player leaderboards over natural periods.
9. Goal-type/share rankings with denominator-aware thresholds.
10. Compound narrative selection: combine compatible proven findings without double counting evidence.

## Publication gate

A finding should answer at least one of: Is it a record? Is it a first? Where does it rank? When did it last happen? How rare is it? Is the historical gap meaningful? Does it materially strengthen another Gold story?

If none applies, it is normally supporting context rather than premium Stat Pack material.
